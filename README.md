# Employee Management System (Django/DRF)

Учебный проект по управлению сотрудниками и рабочими местами. Включает API на Django REST Framework, JWT-авторизацию, Swagger-документацию и Docker-инфраструктуру.

## Технологии
* Python 3.12
* Django 5.x
* Django REST Framework
* PostgreSQL
* Docker / Docker Compose

## Запуск проекта через Docker

1. Убедитесь, что у вас установлены **Docker** и **Docker Compose**.
2. В корневой папке проекта выполните команду:
   ```bash
   docker compose up --build
